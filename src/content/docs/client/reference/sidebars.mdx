title: Sidebar views
description: Sidebar views that come built-in with NeuroPilot.
---

As of version 2.3.0, NeuroPilot has its own sidebar view container. This is placed on the right side by default (matching Copilot Chat) and currently comes with these views by default.

## Action Permissions

The Action Permissions view complements the RCE system by being the configuration screen for actions in permissions V3, the replacement for the old categorical-based configurations.

This view allows you to fine-grain your permissions down to the action level. Each registered action can be set to one of Autopilot, Copilot or Off. For convenience you can also toggle an entire category to one of those settings.

These settings are stored in VS Code settings as an object.

## Action Execution History

The Action Execution view shows the actions that were executed previously. This persists across sessions and across the view being opened and closed.

There are separate colours and separate icons to indicate how an action execution went. For example:

- Successful action executions have a green colour and a tick icon.
- Failed actions have a red colour and a cross icon.
- Executions that threw an exception have a black background.

These colours are also customisable with your VS Code theme.

## Images

The Images view is a fun little view showcasing some images in your editor. Just something fun to look at while you are editing.
