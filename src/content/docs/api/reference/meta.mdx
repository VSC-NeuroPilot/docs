---
title: Companion metadata
description: Information on the metadata of a companion.
---

When registering a companion, you need to pass in an object to the `Companion` constructor.

The metadata model has the following types (also viewable in the types package):

```ts
export interface CompanionMeta {
    name: string;
    author: string;
    docs: string;
    contributes: CompanionContributions[];
}
```

- `name`: The display name of your companion. Will be displayed in NeuroPilot's UIs whenever your extension needs to be identified.
- `author`: The companion author's name (aka you).
- `docs`: A URL to your companion's documentation sites. Examples of links that work here include: your own docs, your companion's repository, marketplace, etc...
- `contributes`: An array of strings that shows your companion's contribution points. See below.

### Companion contribution points

Companion contribution points are declarations of what the companion wishes to do.

For each contribution point, they allow the companion to contribute the following:

- `actions:manage` - Add, remove, register and unregister the companion's own actions to/from the actions registry
- `actions:manage_others` - Register and unregister other companion's actions to/from Neuro.
- `actions:inject` - Inject into NeuroPilot's built-in actions (maybe also allow injecting to non-vanilla actions as well?)
- `actions:process` - Process actions after RCE
- `actions:force` - Force actions from Neuro
- `changelog` - Allows Neuro to view the companion's changelog via `get_changelog`
- `context` - Send context to Neuro
- `cursor:get` - View Neuro's cursor
- `cursor:set` - Move Neuro's cursor
- `images` - Add to images carousel (currently unused)
