The action APIs are a set of APIs related to actions, such as adding/removing actions from the registry, registering or unregistering actions from Neuro, and more.

## `addActions`

*Requires `actions:manage` declared in contribution points*

This function adds RCE actions to the registry of actions. This surfaces the action in the action permissions UI (unless hidden), allows RCE to handle it, and (unless otherwise overridden) registers the action name, description and schema to Neuro.

The model of RCE actions can be found in the types package. {/* I am not repeating it here again */}

## `removeActions`

*Requires `actions:manage` declared in contribution points*

This function removes RCE actions using the name from the registry of actions. This only allows actions registered by that companion to be removed.

## `registerAction`

*Requires `actions:manage` or `actions:manage_others` declared in contribution points*

This function registers actions already added to the registry to Neuro.

If `actions:manage_others` is declared in contribution points, this function will allow regitering other companions' actions.

## `unregisterAction`

*Requires `actions:manage` or `actions:manage_others` declared in contribution points*

This function unregister actions already added to the registry from Neuro.

If `actions:manage_others` is declared in contribution points, this function will allow regitering other companions' actions.

## `injectIntoActions`

*Requires `actions:inject` declared in contribution points*

This function allows companions to inject into other companions' actions.
These will allow replacing some or most of the properties on an action.

<Aside type="caution">

Note that injection support is still in early preview. Do not expect stability quite yet.

</Aside>

## `onDidAttemptAction`

*Requires `actions:process` declared in contribution points*

This function subscribes a listener to execution status events. This function has the same type signature as a VSCode Event interface.
