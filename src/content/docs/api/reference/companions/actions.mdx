The action APIs are a set of APIs related to actions, such as adding/removing actions from the registry, registering or unregistering actions from Neuro, and more.

## `addActions`

*Requires `actions:manage` declared in contribution points*

This method adds RCE actions to the registry of actions. This surfaces the action in the action permissions UI (unless hidden), allows RCE to handle it, and (unless otherwise overridden) registers the action name, description and schema to Neuro.

The model of RCE actions can be found in the types package. {/* I am not repeating it here again */}

## `removeActions`

*Requires `actions:manage` declared in contribution points*

This method removes RCE actions using the name from the registry of actions. This only allows actions registered by that companion to be removed.

## `registerAction`

*Requires `actions:manage` or `actions:manage_others` declared in contribution points*

This method registers actions already added to the registry to Neuro.

<Aside type="caution">

This method **bypasses any obstructions for registering the action via other methods.**

This means that:

- `autoRegister: false` will not block this method from working.
    - If you wish to check for this property, you can choose to get the action's metadata and check the `autoRegister` property.
- The `registerCondition` method will not be called to check registration eligibility.
    - If you wish to check for this method, you can choose to get the action's metadata and check the value returned from the `registerCondition` method.

</Aside>

If `actions:manage_others` is declared in contribution points, this function will allow registering other companions' actions.

## `unregisterAction`

*Requires `actions:manage` or `actions:manage_others` declared in contribution points*

This method unregister actions already added to the registry from Neuro.

If `actions:manage_others` is declared in contribution points, this function will allow registering other companions' actions.

## `reregisterAllActions`

*Requires `actions:manage` or `actions:manage_others` declared in contribution points*

This method un-registers and re-registers all actions from and to Neuro automatically.
Each action will only be registered if the `autoRegister` property is `true`/omitted and the `registerCondition` method is either omitted, or when called, returns `true`.

## `injectIntoActions`

*Requires `actions:inject` declared in contribution points*

This method allows companions to inject into other companions' actions.
These will allow replacing some or most of the properties on an action.

<Aside type="caution">

Note that injection support is still in early preview. Do not expect stability quite yet.

</Aside>

## `onDidAttemptAction`

*Requires `actions:process` declared in contribution points*

This method subscribes a listener to execution status events. This function has the same type signature as a VSCode Event interface.
