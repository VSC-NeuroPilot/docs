---
name: Action models
description: Object models for actions 
---

An RCE action is a superset of a normal Neuro action, and a Neuro action can be (mostly) convertible to an RCE action as is.

An RCE action extends the usual action object interface with the following properties:

- `schema` - Not technically an extra property, however there are changes. The schema in an RCE action is allowed to be either a normal JSON schema, or a schema from a validation library that conforms to the [Standard JSON Schema](https://standardschema.dev/standard-json) specification.
- `handler` - The function that will handle this action. This is the only extra property that is required.
- `displayName` - Allows the action to set a human readable name when displayed on the Action Permissions UI.
- `category` - Assigns a category to the action which will group the action with other actions that specify the same category.
- `validators` - An object which describes the action's validators. The object has `sync` and `async` properties for synchronous and asynchronous validators, respectively.
- `preview` - A function that returns a Disposable-like interface (i.e. `(ctx) => ({ dispose: () => unknown })`). This is used to allow the action to display a visual effect when an action is in Copilot mode and is awaiting permission for proper execution.
- `cancelEvents` - An array of functions that return a cancel event object, which allows NeuroPilot to auto-cancel Copilot mode requests when certain events happen.
- `promptGenerator` - A string or function that returns a string, which is used when generating the Copilot mode prompt. It can be `null` if the action is never intended to be in Copilot mode.
- `defaultPermission` - The default permission level for the action. Defaults to off.
- `autoRegister` - Controls if reregistering all actions will automatically register this action or not. If explicitly `false`, the action can only be registered via `registerAction`.
- `hidden` - Determines whether or not the action is shown in the Action Permissions UI.
- `registerCondition` - If set, the action will only be registered if the function returns `true`.
